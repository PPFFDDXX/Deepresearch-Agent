# 知舟试点验收记录

> 虚构演示文档，所有测量值均为合成数据，不代表真实产品表现。

- 文档编号：XL-TEST-003
- 版本：1.0
- 记录日期：2026-09-25
- 负责人：产品部林知远

## 1. 评估口径

评估集包含 50 个问题，其中 40 个在模拟知识库中有答案，10 个没有答案。所有指标来自这 50 个问题的离线人工核验，不包含生产流量。检索命中指有答案问题的前 3 个检索片段中至少一个包含标准答案依据。

## 2. 验收门槛与实测

| 指标 | 验收门槛 | 实测结果 |
| --- | --- | --- |
| 有答案问题的检索命中率 | 至少 90% | 37/40，即 92.5% |
| 有答案问题的回答正确率 | 至少 85% | 35/40，即 87.5% |
| 无答案问题的正确拒答率 | 至少 90% | 9/10，即 90% |
| 50 个回答的来源标注率 | 100% | 50/50，即 100% |
| 端到端响应时间 P95 | 不超过 5 秒 | 4.2 秒 |

## 3. 遗留问题

3 个有答案问题未命中依据，原因是相关条款被切分到不同片段。5 个有答案问题回答错误，其中 2 个发生在已命中依据的情况下。1 个无答案问题错误生成了公司融资金额。来源标注率只衡量是否附有来源，不证明来源支持回答内容。

## 4. 验收结论

本次试点达到表中全部数值门槛，同意继续内部试点。该结论不等于批准上线生产环境。扫描版 PDF、权限隔离和更大规模文档检索尚未完成验收。
